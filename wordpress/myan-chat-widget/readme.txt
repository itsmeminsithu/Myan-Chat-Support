Embed a Myan Chat Support server widget on public WordPress pages.

== Installation ==
1. Install and configure the standalone Myan Chat Support PHP/MySQL server.
2. Upload this plugin under Plugins > Add New > Upload Plugin.
3. Set the chat server HTTPS URL and public website key under Settings > Myan Chat Support.
4. Add the WordPress site's origin to the allowlist on the chat server.
5. Enable the widget and test on a public page.

The website key is public. Do not enter installer keys, database passwords or private credentials into WordPress settings.
